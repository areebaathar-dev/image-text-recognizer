Image Text Recognizer

Privacy

This is a short, plain-language summary of how this tool handles your data.

What happens to an uploaded image

When you scan an image, it is sent to the server, saved briefly under a random temporary name, and read by the OCR engine. The file is deleted immediately afterward, whether the scan succeeds or fails. No copy of the image is kept.

What is not collected

The original filename is never stored. Extracted text is returned directly to your browser and is not logged or saved on the server. No accounts, cookies, or analytics are used by this tool.

Rate limiting

Requests are limited per IP address to keep the service responsive. This limit is enforced in memory and is not tied to any stored personal data.

Questions

This is an open-source project. You're welcome to read the source code directly to verify any of the above.
